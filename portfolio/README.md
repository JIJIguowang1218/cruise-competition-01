# Portfolio / 作品集制作内容

> 本文件夹用于整理与作品集制作相关的设计产出、A3 文档、设计规范与 SVG 资源。
> 目的：把零散分布在设计目录和桌面上的最新成果集中管理，便于后续作品集排版、演示和交付。

---

## 目录说明

| 目录 | 内容 |
|---|---|
| `a3-document/` | A3 产品介绍书 HTML 各版本，核心文件为 `a3-document-web.html` |
| `design-specs/` | 设计规范文档与 SVG 展示：ClarSyn A3 规范（当前默认）、Claude Code 桌面端 UI 规范（历史/备查） |
| `copy/` | A3 产品介绍书文字稿与全量文案 |
| `planning/` | A3 页面规划、逐页架构表 |
| `brand/` | ClarSyn 品牌规范与品牌 SVG 素材 |
| `samples/` | 页面样板与版式预览 HTML |
| `research/` | GitHub 流程图 / 复杂关系图资源调研 |
| `svg-pm-diagrams/` | 面向 AI 产品经理叙事与流程图的扁平 SVG 图集 |
