## 0. 约束与设计目标

### 硬约束

| 项 | 内容 |
|---|---|
| 画幅 | 9:16 竖向；宽 594–840mm 待定（建议 700×1244mm，见 §6） |
| 素材现状 | 第 III 幕及以前已绘制可直接选取；IV/V/VI 中仅 **Agent 架构允许新制作**，其余若有时间只做轻量新图 |
| 命题要求 | 必须呈现"问题定义—系统设计—技术路径—应用验证"完整逻辑（评委按此打分） |
| 赛道特征 | 船舶专业学生为主，工程口味重；我方差异化武器 = 工业设计审美 + 真高保真原型 |
| 提交物呼应 | 2 分钟演示视频、可运行 Demo（加分项）→ 展板留二维码位 |

### 三个设计判断

1. **展板是"3 秒 + 30 秒"两层阅读**：3 秒远看只读到标题、大数字、深色 UI 主视觉；30 秒近看读各带结论句。作品集正文段落一句话都不许直接搬。
2. **一条 spine 讲完**：真问题 → 真判断 → 一个系统 → 一条治理管道 → **真做出来了（UI 实证）** → 技术路径 → 验证路径。第三幕 12 页机制不逐页上展板，靠"1 张总谱 + UI 截图特写"承载。
3. **UI 截图是论点的证据，不是装饰**：每张特写必须证明一条机制（HITL / 库外发现 / 可解释 / 分级授权），配一句白话标注。

## 3. UI 截图使用方案

### 占比决策：**约 35%（建议区间 33–40%）**

用户直觉 1/3–1/2，取靠近 1/3 的位置，理由：

1. 深色大屏面积超过 40% 时整版远观发"黑沉"，与"清新好看"目标冲突；浅底 + 深色 UI 悬浮的对比感在 30% 上下最精神；
2. 船舶工程背景评委对"截图代替论证"天然警惕，命题要四段逻辑——35% 已是全场最高视觉占比，再高会被读成"界面比赛"而非系统方案；
3. 同赛道其他队伍基本是图表+文字，35% 精致截图已构成碾压级审美差，边际收益不需要到 50%；
4. 预算花在**裁切与编排密度**上，而不是整屏面积。

占比构成：E 带大屏+特写 25% ｜ 标题/验证带中 UI 衍生元素约 5% ｜ C 带工作台终端小窗约 5%。

## 5. 视觉规范（"清新"的具体做法）

- **底色**：全版浅色 `#F4F5F7`/白（沿用已定稿的内容页背景规范）；深色只出现在 UI 屏与一级标题字上，全版深浅面积比约 30:70；
- **分带**：用 0.5 条细线和留白分带，**不用彩色大色块**；每带序号 01–05 用小字标签（约 4mm 字高），不做花哨章节牌；
- **语义色沿用产品口径，全版 ≤4 色 + 中性色**：
  - 品牌蓝绿 = AI / 正常流（系泊绿）
  - 红 = 人工控制、L4 船长决策区（克制使用，全版红点不超过 5 处）
  - 琥珀 = 挂起/超时
  - 蓝 = X 库外
- **字体**：中文无衬线（思源黑体/苹方同族），数字与英文可用一款几何无衬线或半衬线做对比；全版不超过 2 个字族；
- **卡片**：圆角统一、1 层极淡投影；特写卡用 1.5–2mm 描边或投影悬浮，不堆边框花样；
- **纹理**：大留白即风格。每带文字面积 ≤ 该带 30%，结论句加粗、其余全是词与图。

## 6. 制作规格

- **推荐尺寸 700 × 1244mm**（9:16）：折中宽度，印刷成本与可读性平衡；所有图件矢量，594/840 两版等比导出无损；
- 若组委会给统一板幅，以实际宽度重算高度（宽 × 16/9），网格比例不变；
- 出血 3mm，安全边距 24mm；12 列网格（列宽 ≈47mm，gutter 8mm）；
- 色彩模式 CMYK，截图位图 300dpi 等效（按 DPR=2/3 重导，见 §3）；
- 材质建议：KT 板/雪弗板哑光覆膜（避免展厅灯光反光淹没深色 UI 细节）。

## 7. 内容诚信口径（沿用 presentation-strategy）

1. 三个数字卡：6–7h、16h→2h 标平台来源（真实用户评论）；20–45min 必须标"推演估算"；
