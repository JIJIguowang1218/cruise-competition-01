# P9-1 L4 适用性：船长权限边界证据与应用（决策分析）

> 归档：2026-09-04。基于 `research/round2/source-archive/06-master-authority-and-shipboard-org.md` 的证据，给出 P9-1 的 **L4 判据重定义** 与 **受影响文件清单**（评审用，勿直接批量改动，逐文件确认后动手）。

## 1. 核心结论（一句话）

**L4 从"大事标签"重定义为"船长决策区"——触发判据不是"影响大不大"，而是"这个决定船长是否有不可让渡的负责义务"（安全 / 群体 / 不可逆 / 法定对外）。P9-1 的下船调度主链路默认 L2/L3（宾客运营线内闭环），船长只做知会/抄送，仅当执行期触发上述判据才升 L4。**

## 2. 证据支柱（详见 06 档案）

| 支柱 | 证据 | 项目含义 |
|---|---|---|
| 1 船长法定权限限定于安全/防污染 | ISM Code §5.2（A.741(18) 经 SOLAS Ch.IX 强制；IMO 官网措辞限定"security/safety/environment"） | 常规运营决定船长可委托 |

| 4 紧急/群体才组织整体介入 | Mega Cruise Ships Crowd Management(2016) | 常规 L2/L3，紧急 CMC 才到船长 |

## 3. L4 判据重定义（建议口吻，供拍板）

### 3.1 触发器（任一即上 L4）

1. **安全不可逆**：人身/公共安全、下船中海况恶化须紧急中止、火警/疏散、人员落水/医疗送岸（对应既有 E13–E16/E30，不变）
2. **群体必达**：群体滞留/骚乱/拒绝下船（E20 不变）；高压群体情境下的全船级响应
3. **法定对外责任**：需船长代表船公司/船旗国应对外部（海事当局、港口国检查、警方、保险、媒体）
4. **不可逆高后果且无代码级缓释**：审核门判断该决策一旦执行无法回退且影响面为全船/跨港

### 3.2 反向测试（一句话口诀）

> 船长此刻正在驾驶台忙碌，这个决定不找他也能被正确做掉吗？
> 能 → 不上 L4。

### 3.3 等级语义变更对照

| 维度 | 旧口径 | 新口径 |
|---|---|---|
| L4 含义 | 紧急/高后果事件 | **船长决策区**（取决于决策权归属） |
| 触发来源 | 事件等级 | 事件等级 × 决策权归属判据 |
| 船长在 P9-1 角色 | 审批下船/整体方案 | **知会/抄送**（不阻塞）；仅在安全/群体/法定扳机上升级为审批 |
| 常规下船方案重排 | 可达 L4 | **L2/L3**（宾客运营线值班确认/运营经理审批） |

## 4. P9-1 落地建议（泳道图口径）

```
外部航变决定已成立（气象/海事预警 + 船公司航变决定 + 船长安全确认，ClarSyn 不承担"发现台风/做航变"）
        │  （输入：航变方案 + 修订ETA + 港口窗口 + 本船状态）
        ▼
船基推演：登离船/接驳/时间窗/船员任务 → 方案生成（附推理附件）
        │
        ├─ 常规调度 ──► L2 值班/宾客服务确认 ──► L3 运营经理/宾客运营经理审批 ──► 执行
        │                   │                      │（船长：知会/抄送，不阻塞）
        │                   └─ 超时默认执行+审计（快）；涉偏离阈值 → L3
        │
        └─ 执行期触发安全/群体/法定/不可逆 ──► L4 船长决策区（紧急审批）
```
- **船长通道 = 抄送/知会**（第一版泳道图应画"抄送通道"而非"审批通道"）。
- **超时双路径**：常规方案超时默认执行 + 审计回写；涉风险方案超时自动升级 L4。
