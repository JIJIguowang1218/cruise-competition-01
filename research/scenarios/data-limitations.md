# 数据收集局限记录

## 可用的数据通道

| 通道 | 能力 | 适合什么 |
|------|------|---------|
| **浏览器直接访问** | 可读取 HTML 文本快照、JS 提取、截图 | 无验证码的新闻/行业媒体（如钛媒体） |
| **web_search (DuckDuckGo)** | 间歇性可用，短查询（<8词）成功率更高 | 发现文章 URL、关键词搜索 |
| **GitHub API (curl)** | 稳定可用 | 搜索开源项目、读取 README |
| **百度百科** | 浏览器可读 | 船型参数、设施清单 |

## 被阻挡的平台

| 平台 | 阻拦方式 | 重要性 | 尝试过的绕过 | 结论 |
|------|---------|:--:|-------------|------|
| 小红书 | 需登录 | 极高 | 克隆 RedNote API、redbooks、Scraper | 均需 Cookie 或付费 API |
| 携程 | JS渲染+反爬 | 高 | curl、浏览器 | 返回动画404/空白 |
| 什么值得买 | 验证码弹窗 | 中 | 浏览器 | 验证码覆盖内容 |
| 知乎 | UTF-8编码报错 | 中 | 浏览器多次 | HTTP 层即失败 |
| 百度搜索 | 验证码 | — | 浏览器 | 直接触发验证 |
| Cruise Critic | DataDome CAPTCHA | 中 | 浏览器 | 国际对标数据无法获取 |
| TrustPilot | 连接验证 | 中 | curl、浏览器 | 反爬 |
| Reddit | 空返回 | 中 | curl API | 限流或封锁 |

## 试过的反爬工具

| 工具 | 结论 |
|------|------|
| Firecrawl (141K⭐) | 需 API Key 付费或 Docker+PostgreSQL 自部署 |
| RedNote API (29⭐) | 付费 SaaS，注册送少量免费额度 |
| redbooks (21⭐) | 需 Windows GUI + 人工扫码登录小红书 |
| wzk1015/Scraper (29⭐) | 需手动从浏览器提取 Cookie |

**根因**：所有中文UGC平台（小红书/携程/知乎）都要求登录态。纯自动化绕过不存在。
