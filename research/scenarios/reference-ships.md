# 参考邮轮：爱达·魔都号 & 爱达·花城号

> 两艘船均由中船集团上海外高桥造船有限公司建造，作为新船设计的规模参考。
> 竞赛方案服务于外高桥的后续新船，而非对现有船只的改造。
> ⚠ 数字核对：本文件已于 2026-08-17 按 round2 批1 流②（`research/round2/batch1/02-ship-engineering-baseline.md`）校对；引用时以流②为准（含口径标注）。v3 红线：**禁止引用 800 人剧院、未标口径的旅客量**。

## 爱达·魔都号（Adora Magic City）

**中国首艘自主建造的大型邮轮**，2023年11月4日交付，2024年1月1日首航。

### 基本参数

| 参数 | 数值 |
|------|------|
| 总吨位 | 13.55万吨 |
| 总长 | 323.6米 |
| 型宽 | 37.2米 |
| 最大高度 | 72.2米 |
| 设计吃水 | 8.26米 |
| 最大载客量 | 5246人 |
| 船员编制 | ~1292人（全船约6500人） |
| 舱室总数 | 2826间（乘客2125间 + 船员701间） |
| 甲板层数 | 16层上层建筑生活区 |
| 设计图纸 | 15万页（旧文件"15万份"已按 ②流 S27 修正），总重2.1吨 |

### 工程规模

- 107个系统、5.5万个设备、2500万个零部件
- 4750公里电缆、365公里管系、120公里风管
- 吊舱式电力推进：总功率62.4MW，2台16.8MW吊舱推进器
- 减摇鳍过滤88%摇晃，艏侧推实现原地调头
- 消防：高压水雾系统40+公里，1.1万+雾化喷头
- 救生：20艘救生艇（每艘314人）

### 通信系统

- 5G + WiFi + 卫星天地一体组网
- 船载5G基站 + 轻量级核心网本地算力
- 近海：5G/WiFi6千兆速率
- 远海：卫星回传 + 本地算力节省带宽

### 设施分布

| 类别 | 内容 |
|------|------|
| 餐饮 | 官方口径全船 22 间餐厅及酒吧；央视口径 9 个餐厅（可容 1500 多人同时就餐）；"3 个免费自助"数量未获公开验证 |
| 娱乐 | 大都会剧院（**可容纳近千人**，旧"800 人"已按 ②流 S10/S39 更新）、水上乐园、健身房、球场 |
| 购物 | 海上最大免税店（200+品牌） |
| 亲子 | 海上探索营（AI+STEAM课程） |
| 医疗 | 诊室配备无影灯，可做应急处理 |
| 艺术 | 艺术走廊、敦煌主题艺术展 |
| 空调 | 5套主冷媒水系统 + 7套应急制冷，100台中央空调器 |

### 运营数据（注意口径：海关"进出境艘次/人次" ≠ 商业航次/宾客数）

| 指标 | 2024年 | 2025年 | 累计 |

### 航线

- **母港**：上海吴淞口国际邮轮港（主）、青岛（季节性）、深圳（2026.8起）、天津（2027年起）
- **目的地**：日本（福冈、长崎、佐世保、神户）、韩国（济州）、越南（顺化、下龙湾、芽庄）、马来西亚（亚庇）、文莱（麻拉）
- **航程**：4晚5天 / 5晚4天 / 7晚8天 / 9晚8天
- **特色航次**：无目的地海上游（3天2晚）、海上电影节、京剧/相声主题、哪吒闹海主题

## 爱达·花城号（Adora Flora City）

**第二艘国产大型邮轮**，2022-08-08 开工，2026-03-20 出坞，2026-05-16 起试航 12 天 11 夜（一次通过 149 项海试），计划 2026-11-06 在上海交付、**2026-11-22 广州南沙首航**（②流 S01/S02）。

### 基本参数

| 参数 | 数值 |
|------|------|
| 总吨位 | 14.19 万吨（精确值，比魔都号 +0.64 万吨） |
| 总长 | 341 米（比魔都号长 17.4 米） |
| 型宽 | 37.2 米 |
| 满载游客 | 5232 人（比魔都号 -14 人） |
| 客房 | 2130 间（比魔都号 +5 间客舱） |
| 甲板层数 | 官方未见精确数字（第三方 16 层），待规格书 |
| 船员 | 已招募超 1500 名（官方精确编制未发布；第三方约 1300 人） |
| 母港 | 广州南沙国际邮轮母港（深圳、香港三港联动） |

### 设施（相对魔都号升级点，②流 S06）

- 中庭面积翻倍、商店增至 1524 平方米、水上乐园面积扩大近 50%、巴伐利亚套房 +47%、最大套房面积翻倍、增设啤酒餐厅
- 四部原创大秀、花城广场、购物区、儿童俱乐部、SPA
- 餐厅酒吧数量口径不一：官方发布会 28 间 vs 上观 26 间（待官方规格书澄清）
- 满足 IMO Tier III 排放、5 套柴油机 SCR；全船检验项目超 12 万个

### 航线

- 首航：广州 → 香港 → 越南顺化，6天5晚；首航季 2026-11-22 至 2027-01-02 共 6 个航次（含 9 天 8 晚南洋线、17 天 16 晚东南亚六国"海丝发现之旅"、3 晚 4 天香港跨年）

## 对新船设计的参考意义

| 维度 | 魔都号 | 花城号 | 新船可参考 |
|------|--------|--------|-----------|
| 吨位 | 13.55万吨（运营方另有 13.62 万 GT 口径） | 14.19万吨（精确值） | 大概率13.5-15万吨级 |
| 载客 | 5246人 | 5232人 | 5200人级别（后续新船可能主动降密度） |
| 船员 | ~1292人（交付在岗）/运营期约1300 | 已招募1500+（官方精确编制未发布） | 1200-1300人（花城待官方） |
| 客舱 | 2125间 | 2130间 | 2100+间 |
| 设施密度 | 16层/2826间（总舱，含船员701） | 16层/2130间（客舱口径） | 花城客舱 +5 间但公共空间更大（中庭×2）；旧文件混比"总舱/客舱"已修正 |
| 航线 | 日韩为主（2026Q1 删日本线、12 月恢复） | 东南亚为主（首航季） | 双航线能力；航线随地缘动态切换 |
| 船价 | — | — | 魔都号合同造价 7.7 亿美元、约 55.4 亿元（官方调查报道口径，非估计） |
