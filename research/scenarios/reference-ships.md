# 参考邮轮：爱达·魔都号 & 爱达·花城号

> 两艘船均由中船集团上海外高桥造船有限公司建造，作为新船设计的规模参考。
> 竞赛方案服务于外高桥的后续新船，而非对现有船只的改造。

---

## 爱达·魔都号（Adora Magic City）

**中国首艘自主建造的大型邮轮**，2023年11月4日交付，2024年1月1日首航。

### 基本参数

| 参数 | 数值 |
|------|------|
| 总吨位 | 13.55万吨 |
| 总长 | 323.6米 |
| 型宽 | 37.2米 |
| 最大高度 | 72.2米 |
| 设计吃水 | 8.26米 |
| 最大载客量 | 5246人 |
| 船员编制 | ~1292人（全船约6500人） |
| 舱室总数 | 2826间（乘客2125间 + 船员701间） |
| 甲板层数 | 16层上层建筑生活区 |
| 设计图纸 | 15万份，总重2.1吨 |

### 工程规模

- 107个系统、5.5万个设备、2500万个零部件
- 4750公里电缆、365公里管系、120公里风管
- 吊舱式电力推进：总功率62.4MW，2台16.8MW吊舱推进器
- 减摇鳍过滤88%摇晃，艏侧推实现原地调头
- 消防：高压水雾系统40+公里，1.1万+雾化喷头
- 救生：20艘救生艇（每艘314人）

### 通信系统

- 5G + WiFi + 卫星天地一体组网
- 船载5G基站 + 轻量级核心网本地算力
- 近海：5G/WiFi6千兆速率
- 远海：卫星回传 + 本地算力节省带宽

### 设施分布

| 类别 | 内容 |
|------|------|
| 餐饮 | 9个餐厅（3个免费自助），最大餐厅可容1500人 |
| 娱乐 | 800人大剧院、水上乐园、健身房、球场 |
| 购物 | 海上最大免税店（200+品牌） |
| 亲子 | 海上探索营（AI+STEAM课程） |
| 医疗 | 诊室配备无影灯，可做应急处理 |
| 艺术 | 艺术走廊、敦煌主题艺术展 |
| 空调 | 5套主冷媒水系统 + 7套应急制冷，100台中央空调器 |

| 航次 | 84 | 170 | 337 |

### 航线

- **母港**：上海吴淞口国际邮轮港（主）、青岛（季节性）、深圳（2026.8起）、天津（2027年起）
- **目的地**：日本（福冈、长崎、佐世保、神户）、韩国（济州）、越南（顺化、下龙湾、芽庄）、马来西亚（亚庇）、文莱（麻拉）
- **航程**：4晚5天 / 5晚4天 / 7晚8天 / 9晚8天
- **特色航次**：无目的地海上游（3天2晚）、海上电影节、京剧/相声主题、哪吒闹海主题

## 爱达·花城号（Adora Flora City）

**第二艘国产大型邮轮**，2022年8月开工，2026年3月20日出坞，预计2026年11月首航。

### 基本参数

| 参数 | 数值 |
|------|------|
| 总吨位 | ~14.2万吨（比魔都号大0.65万吨） |
| 总长 | 341米（比魔都号长17.4米） |
| 型宽 | 37.2米 |
| 满载游客 | 5232人 |
| 客房 | 2130间 |
| 甲板层数 | 16层生活娱乐区域 |
| 母港 | 广州南沙国际邮轮母港 |

### 设施

- 大型演艺中心、大型餐厅、特色餐馆、酒吧、咖啡馆
- 购物广场、艺术走廊、儿童中心、SPA、水上乐园

### 航线

- 首航：广州 → 香港 → 越南顺化，6天5晚
