# 调研与证据

> 本项目无企业内部访谈条件，需求证据来自桌面研究与多源公开证据。本目录保留完整过程，供核查方法与结论。

## 证据分级

| 等级 | 定义 |
|---|---|
| L0 | 官方 / 一手文件（政府公告、法规、企业公开披露） |
| L1 | 权威媒体、机构报告、学术文献 |
| L2 | 用户生成内容（UGC、论坛、投诉） |
| L3 | 推断（仅作线索，不作为结论依据） |

置信度按独立来源数量判定：Strong ≥5、Moderate 3–4、Emerging 2、Weak 1；不基于 Weak / Emerging 证据做方向推荐。

## 目录

| 目录 | 内容 |
|---|---|
| `evidence/` | 证据总台账（`evidence-index.md`）、六流调研报告、来源原文归档、痛点合成 v3 |
| `decisions/` | 方向提案、痛点 × AI 匹配、评审偏好提炼 |
| `round3/` | 补充研究：港口时间窗、船员模型、AIS 弱信号、台风报文、船员分组等 |
| `scenarios/` | 邮轮场景、参考船型、数据可得性局限记录 |
| `method/` | AI 产品经理方法论学习笔记 |

## 说明

一手资料缺失的情况（口岸实时数据、船司内部数据）记录在 [`scenarios/data-limitations.md`](scenarios/data-limitations.md)，未做推测性补全。
