# 痛点原文素材库（Source Archive）

> 用途：为方案书、Demo 剧本、AI 价值论证提供“可直接引用的痛点原文素材”
> 说明：这里不是证据台账，而是按场景整理的引用素材库
> 关联：`research/round2/evidence-index.md` 是来源总台账；本目录是场景化素材

## 目录

- `01-dining-crowd.md`：餐饮拥挤/排队/抢餐
- `02-embark-disembark.md`：登离船拥堵/等待
- `03-port-transport.md`：港口接驳/打车/短驳
- `04-itinerary-change-compensation.md`：航变/赔偿/群体维权
- `05-entertainment-public-space.md`：娱乐/公共空间资源竞争

## 素材字段

每个素材尽量包含：

- 原始描述/标题/可引用摘要
- 来源名称、日期、URL、证据等级
- 适合引用的原句
- 可用于方案书/Demo 的“场景化描述”

## 限制说明

- 当前二轮调研多为标题/摘要级证据，登录墙后的正文未纳入。
- 后续如有关键全文，可继续补充到对应文件。
- 新增素材请保持“可追溯”，不要写无法回溯来源的断言。
