**导航结论（供 P1 设计锁定边界）**：
- P1 是唯一"壳"，所有页从这里进出；**单一窗口应用**，无多路由割裂。
- P2 嵌入 P1 主区（默认即时间轴常驻）或全屏 Tab —— 决策点 1。
- P3/P4/P5 从 P1 进入，形态（主区切换/弹层/右面板/独立平板）在 P1 上当场定 —— 决策点 1/3。
- P6 独立终端，不占 P1 空间（只联动）。
- P7/P8/P9 可选，MVP 先 P1–P6。

### 1.2 P1 功能与事件条（沿用 specify P1 + 0.x 全局约定）
- 事件条字段：`[等级色条] 事件ID 分类 状态徽标[待确认/待审批/待查看/接管] 已耗时/倒计时条 处置角色`
- 事件条三态：可操作 / 只读(锁) / 不可见(按角色重渲染)
- 数据三态小点：绿=真 蓝=模拟 灰=不可得（图例常驻顶栏）

### 1.3 低保真上待你当场的 5 个决策点（把文字题搬进图里）
1. **导航模型**：P2 就作 P1 主区（时间轴常驻）还是独立 Tab？→ 低保真中部默认"常驻"，你可喊切
2. **P3/P4/P5 形态**：主区切换 / 弹层 / 右侧面板 三选或组合 → 低保真做成可点，三种都试
3. **角色切换**：顶栏角色切换器 模拟登录定向，是否接受 → 顶栏已做，看效果定
4. **联动动画**：决策→P6 触达"实时出现"是否做 → 本次低保真先不做动画，只留标记位
5. **空态/降级**：是否每页都要 → 低保真 P1 先做"降级横幅"与"时间轴空态"两处示意
