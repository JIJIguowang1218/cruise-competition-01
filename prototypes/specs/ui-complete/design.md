### 1.5 P1 布局与交互约定（含原因，改图 / 高保真前必读）

> 本小节集中记录 **P1 已固定的布局做法 + 为什么这么做**，避免后续修改/做高保真时遗忘。时间轴内部状态→图形的"唯一事实源"仍见 `p1-timeline-visual-grammar.md`，两者冲突以语法文件为准。

**1. 四分区布局（监控大屏，1920×1080 基准）**：顶栏 / 左（局势图+操作台日志） / 中（信息端口条+保留区+时间轴+事件卡片带） / 右（处置面板）。原因：大屏态势优先、低交互、值班位长时盯视。

**2. 顶栏**：
- 本地时间 **放大显眼**（24px 时钟、小字"本地时间·船时"）——船员以船时为基准；**韧性 T0 用小号弱化灰chip**。
- 模式术语已专业化：**在航 Underway / 离泊 Casting off / 靠泊 Berthing / 系泊 Moored**（依 SOLAS/COLREGS 泊位相位）。
- 右上角**登录头像点开切换角色**（模拟登录定向，真实=登录定向；非一排按钮）；角色区=身份/个人。

**3. 左栏**：
- 局势图：抽象顶视邮轮 + 港区，随模式切换（系泊=绿实线、靠泊/离泊=琥珀虚线、在航=当前港/目的港边界点），非靠泊自动收起登离船信息。
- 下方 **操作台日志占满左栏剩余高度**（append-only 只追加滚动，新条目置顶）：所有审批/接管操作 + 事件每步反馈（发现/建议/移交/执行/恢复/异常/升级/库外）各一条，关联痕迹模型 §4.13.2。
- 日志控件：搜索框 + `全部/事件/操作` 过滤 + `⏸暂停` + 条数 + `LIVE·追加中`；⚙ 可开关。
- **操作台设置条在左栏底部**，只保留 **设置 / 等级 / 时段**。原因：设置是"工作台/视图"级，放左栏底部；不放角色附近（那是身份个人，避免混淆）。此条精简过（曾含 清空视图/另存为视图，用户要求去掉）。

**4. 中栏**：信息端口条（点切数据面板）；顶部**保留区（用户"一会再说"，用途未指派，勿擅动）**；事件时间轴（见语法文件）；右侧**事件卡片带**（L4/X 置顶不折叠，L3/L2/L1 分组可折叠，点卡片→与右栏轮廓融合，全程不弹窗=安全领域要求）。

**5. 右栏（处置面板）**：
- 内嵌 **Tab：决策卡 / 审批流 / 端口·审计**。
- **处置动作（确认 / 下达执行 / 拒绝 / 转接管）只在「决策卡」Tab 内，且固定在卡片内**——审批流、端口/审计只展示流程/审计（端口/审计含专属"导出审计包 PDF"）。原因：动作从各Tab消失、固定在决策卡，避免点附件时按钮位置位移。
- **推理附件「展开 / 收起」在决策卡下方独立面板**，展开后**占满右栏下方空白**、显示 AI 推理全文原文（信号清单→预处理→分类→长链推演→条款检索→置信度分解→方案比对→兜底边界 + 证据引用），信息越详细越好；收起只留一行头部。原因：不弹窗、附件说明性不自动决策（§4.11 / §3.8.1）。

**6. 布局纪律（防两个坑）**：
- `.app` 用 `width:min(1520px,calc(100vw-24px))` + `aspect-ratio:1520/940` + `overflow:hidden` —— **锁死长宽比**（缩放/改窗口不改变比），内部列 `overflow` 内部滚动。原因：曾用 `height:calc(100vh - 20px)` 导致缩放时宽度固定/高度跟视口→长宽比变化，已修复。
- 展开推理附件不得把页面整体顶高 —— 靠 app 定比 + 各列 `min-height:0` + `overflow:hidden`，右栏内部滚动。

**7. 工具/写文件纪律**（agent 备忘）：本工作区写文件用 **python 或 bash 分块 heredoc（每块 <8KB 防截断）**；`str_replace_editor` 会把 `/d/...` 写到 `C:\d\...`（错盘）；写完用 python HTMLParser 校验 div/svg/script 平衡。

**8. 仍待定**：主视觉方向（**深色为主 + day/dusk/night 三挡**，待用户最终拍板）；车道分配是否按角色自适应；KPI 组合定稿；中央栏顶部保留区用途。

### 事件卡片带（时间驱动 · 分区排挤流）
- 五个分区：**L4 / X·库外 置顶，L3/L2/L1 等高拉满**；每区=实时卡区 + 已处置栏（弹窗明细待定，点击仅 toast）。
- 规则：事件发现→顶部插入(pop)；**执行阶段发生→原地变暗(linger，卡片无状态标签)**；新事件到达时最老的"已挤推"linger 做**收入已处置动画**（下坠淡出+绿脉冲+计数+1），其余 linger 标记已挤推 → 排队流 A→B→C。
- 已处置数 = 已收集 + 滞留中；已收集事件打 consumed 标记**永不重入**（防死循环）；集合签名重建（保滚动位置）；拖动/回退 `resetBand` 确定性重推（拖到最早=全空）。

### AI 实时推理监视窗（保留区下半）
