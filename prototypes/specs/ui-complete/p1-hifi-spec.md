# P1 高保真实现规范（p1-hifi-spec.md）v0.1 草稿

> 定位：**船长端高保真纵切（`p1-captain-hifi.html`）的"唯一实现规格 + 设计决策留痕"。**
> 与既有文档关系：功能/状态全集 = `specify.md`；页面/布局/交互约定 = `design.md §1.5`；时间轴状态→图形 = `p1-timeline-visual-grammar.md`；**本文件只承载"视觉实现规格 + 是否协调自洽（防缝合怪）+ 修改/错误回溯"**。
> 用法：**画高保真 / 改高保真之前，先读并更新本文件 → 再动 `p1-captain-hifi.html`**。任何一处视觉取值都必须能从本文件 §2 Design Token 溯源，否则不允许出现。

---

## 0. 为什么需要这份文件（机制说明）

1. **单一事实源**：高保真涉及上百个视觉取值（色/字阶/圆角/间距/阴影/动效）。没有一份规格，后续每次修改都靠记忆/临场，必然漂移。
2. **错误证据可回溯**：借鉴了很多开源项目，若没有"来源映射 + 修改留痕表"，一旦某个样式来源不清，无法判断是"有意借鉴"还是"误抄成缝合怪"，也无法回退到上一个正确版本。
3. **防缝合怪的结构化手段**：本文件强制"**每个视觉元素必须能指到三个来源之一（Design Token / 组件规范 / 页面规范）**"，从机制上杜绝"A 的卡片 + B 的按钮 + C 的配色"式混搭。

---

## 1. 单一设计语言声明（防缝合怪总纲）

### 1.1 总原则
- 我们**只使用一套 Design Token、一条动效语言、一层组件来源**。
- 任何视觉元素都必须能回答"它来自哪个 token / 哪条组件规范 / 哪个页面规范"；答不出来 = 不允许出现在高保真里。
- **配色只用 token，禁止直接用原项目的色值**（哪怕很喜欢某个参考的颜色）。
- 圆角 / 字阶 / 间距 / 阴影 / 动效时长各只有一套，禁止单页内混两套。

### 1.2 借鉴来源映射（每个模块的出处，避免随手抄）
| 功能模块 | 参考来源 | 我们吸收什么 | 怎么统一（不缝合） |
|---|---|---|---|
| 事件时间轴 / 大屏态势 | NASA Open MCT | 深色态势 + 时间轴/时间域概念 + 多面板布局语言 | 只借"时间轴+深色大屏"的构图语言；配色走我们 token |
| 组件 / 表格 / Tab / 通知 / 步骤条 | IBM Carbon | Tabs / DataTable / Notification / Progress 的结构与交互 | 组件结构参照，外观（色/圆角）全部走我们的 token |
| Design Token / 状态层 / 动效时长 | Material 3（理念） | token 口径、State Layer、Elevation、动效时长语义 | 仅借理念，不引依赖（material-web 已 maintenance，不引入） |
| 深色主题 / 无障碍 | Radix Themes / Colors | 深色色阶、focus/aria、对比度 | 色阶只作为我们语义色深底版的参考来源 |
| 状态机 / 动效 | XState + Motion + prefers-reduced-motion | 显式状态机防非法状态；动效缓动 | 动效时长统一 token |
| 大屏多面板 / 图面注解 | Grafana | 时间序列 + Annotation（图面时间注解） | Annotation 样式走 token |

### 1.3 防缝合怪守则（每次改图前自查）
- [ ] 配色全部来自 §2 色板（无游离色值）
- [ ] 一套字阶、一套圆角、一套间距、一套阴影
- [ ] 组件无两套视觉混用（如"Carbon 卡片 + Ant 按钮"）
- [ ] 深色 3 档只做整体亮度/色温偏移，语义色对比度一致
- [ ] 动效时长/缓动统一 token；prefers-reduced-motion 生效

## 2. Design Token（v0.1 草案，画前与用户定稿）

> 深色主视觉 + **day/dusk/night 三档**；三档只改整体亮度/色温，语义色在深底上对比度保持一致。

### 2.1 色板（深底基色 + 语义色深底重标）
| Token | 用途 | 建议初值（待定稿） |
|---|---|---|
| bg-0 | 页面最深底 | #0b0e13（night）/ 依三档上调亮度 |
| bg-1 | 面板底 | #12161d |
| bg-2 | 内嵌/悬浮/卡片 | #1a2029 |
| line-0/1 | 描边/分隔 | #262d38 / #303a49 |
| text-hi/lo | 主/次文字（深底白系） | #e8ecf2 / #8b95a5 |
| ev-detect | 发现段（琥珀，深底重标） | 参考 Radix amber 色阶，取深底对比版 |
| ev-exec | 执行段（绿） | 参考 Radix green 深底版 |
| ev-abn | 异常/升级（红） | 参考 Radix red 深底版 |
| ev-outlib | 库外 X（蓝，虚线框） | 参考 Radix blue 深底版 |
| ev-recover | 恢复点（深绿空心圆） | 同上绿色阶 |
| day / dusk / night | 三档整体亮度与色温 | night 最暗偏冷；dusk 中暖；day 亮且暖 |

> 语义色：琥珀发现 / 绿执行 / 红异常升级 / 蓝库外 / 深绿恢复点——**延续低保真事件状态机语义，仅换深底深底版本**（低模 §5 颜色对照 → 高保真换用本表后的最终值）。

### 2.2 字阶（单一字阶表）
| Token | 用途 | 建议 |
|---|---|---|
| type-xs | 微注/时间轴刻度 | 10px |
| type-sm | 次级信息 | 12px |
| type-md | 正文/卡片 | 14px |
| type-lg | 区块标题 | 16px |
| type-xl | 顶栏时钟/主 KPI | 24px |
| type-display | L4 全屏告警 | 40px+（仅告警态） |

### 2.3 圆角 / 间距 / 阴影（各只一套）
| Token | 值（建议，待定稿） |
|---|---|
| radius-sm/md/lg | 2 / 4 / 8（指挥类界面偏方，勿大圆角） |
| space-1..6 | 4/8/12/16/24/32 |
| elev-1..3 | 卡片/浮层/告警（深底 Elevation，参考 Material 样式但用深底值） |
| focus-ring | 统一 2px 键盘焦点环（深底可见，Radix 方式） |

### 2.4 动效 Token
| Token | 值 |
|---|---|
| dur-fast/mid/slow | 120ms / 180ms / 300ms |
| easing-in/out/standard | cubic-bezier: 标准进出（Material 语义） |
| reduce-motion | prefers-reduced-motion 下全部降到 0/瞬时 |
| 共享元素 | Tab 切换、推理附件展开使用同一 enter/exit 时长 |

## 8. 高保真修改前置检查（2026-08-20 教训固化，防再犯）

> 教训：首次搭高保真时未先对照已拍板的低仿约定，导致漏 L1 车道、车道数/高度比例错、时间轴未贴底、卡片带缺 L1 与"处置中/已处置"区域。
> **规则：任何修改/重建高保真前，必须先逐项核对以下"已拍板约定"原文，再动手。**

- [ ] 时间轴车道：**L4=2、L3=4、L2=6、L1=10** 虚线，车道高度按条数比例（L1 最高），**L1 车道必须存在**（`p1-timeline-visual-grammar.md §8.2`）
- [ ] 事件解剖：发现段→(瞬时)移交竖线→执行段→末尾空心恢复点；红线异常→绿线修复→正常推进；升级=红实线接上级开头；库外=灰矩形（`grammar §8/§11`）
- [ ] 中栏布局：端口条 → 顶部**保留区(弹性放大)** → 事件时间轴**贴底固定** → 右侧**整竖条事件卡片带**（`design.md §1.5`）
- [ ] 卡片带：**L4/X 置顶不折叠**；**L3/L2/L1 各自可折叠（有 L1 组）**；每级内"处置中"可见、"已处置"收进组内折叠区；点卡片→右栏融合不弹窗
- [ ] 分级/分隔：**卡片分层式（底色Elevation+圆角+留白），不得退化成满屏划线**
- [ ] 缩放：固定画布整体 `scale()` 等比（不出现局部放大缩小）
- [ ] 上述任一不符，先改规范再改图，不得靠记忆/临场
