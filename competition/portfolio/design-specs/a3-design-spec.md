## 1. 页面基础

- 页面尺寸：A3 横板（420mm × 297mm），HTML 画布 1600 × 1132
- 实际内容安全边距：左右 64px、上下 28px 左右
- 输出方式：HTML → 浏览器打印为 PDF，或导出 PNG
- 每页统一页眉：左：ClarSyn 小 Logo；右：章节标签 + 页码
- 每页统一页脚：品牌名 + 章节名 + 页码（不写内部文档路径）

## 1.5 页面背景

- 普通页：纯色背景 `#F4F5F7`
- 封面/致谢等特殊页：135° 渐变背景
  `linear-gradient(135deg, #F4F5F7 0%, #EAF1FC 100%)`
- 普通内容页背景：纯色 `#F4F5F7`，对应独立背景文件：
  `portfolio/svg-pm-diagrams/clarsyn-content-background.svg`（1600 × 1132）
- SVG 业务图不内嵌背景，统一叠加该内容页背景文件

## 2. 栅格与布局

- 页面内容区采用左右栏 / 全宽 / 三栏三种版式
- 模块间距：
  - 标题与正文：10–12px
  - 正文与图表：14–16px
  - 卡片间距：14px
- 卡片圆角：18px；模块圆角：14px；小标签圆角：999px

## 3. 字体

- 中文：`Noto Sans SC` / `Microsoft YaHei` / `PingFang SC`
- 英文：`Inter` / `Segoe UI` / `Helvetica Neue`
- 等宽标签：`JetBrains Mono` / `Consolas`
- 标题：36–48px，加粗（页面主标题常用 38px）
- 副标题：18px，加粗
- 导语/正文：16–18px，常规
- 注释/来源：11–13px，灰色
- 数字与时间：使用等宽数字 `font-variant-numeric: tabular-nums`

## 4. 颜色（终版 HTML 为准）

### 基础色

| 名称 | 色值 | 用途 |
|---|---|---|
| BG | `#F4F5F7` | 页面背景 / 图面浅底 |
| PAPER | `#FFFFFF` | 卡片、白底模块 |
| INK | `#1A2233` | 主标题、正文 |
| SUB | `#4A5468` | 次级文字 |
| MUTED | `#8B95A5` | 辅助说明、连线、弱化元素 |
| LINE | `#D8DCE3` | 分隔线、细边框 |
| MODULE | `#F8F9FC` | 浅灰模块底 |
| TAG | `#EEF0F4` | 标签底、表头底 |

### 强调色

| 名称 | 色值 | 用途 |
|---|---|---|
| BLUE | `#3B7DD8` | 主强调：ClarSyn / 关键结论 / 主 CTA |
| AMBER | `#D98A1F` | 副强调：次级分类 / 提醒 / 中间步骤 |
| GREEN | `#237A4C` | 成功 / 恢复 / 正向价值 |
| RED | `#C93A3A` | 最高级别 / 风险 / 危险提示 |

### 浅色底

| 名称 | 色值 | 用途 |
|---|---|---|
| SOFT BLUE | `#EAF1FC` | 蓝底标签、浅蓝强调区 |
| SOFT AMBER | `#FDF3E4` | 琥珀底标签、浅琥珀强调区 |
| SOFT GREEN | `#E8F4ED` | 绿底标签、浅绿正向区 |
| SOFT RED | `#FCEBEB` | 红底标签、风险强调区 |

### 使用原则

- 每页最多 2 个强调色；大面积只使用中性色；
- 图表中颜色只用于区分关键信息，不堆彩色；
- 正文字体色优先 `#1A2233`，说明文字优先 `#4A5468`；
- 连接线/流程线使用 `#8B95A5`，主路径可用 `#3B7DD8` 强调。

## 5. 统一栏目

- 每页固定元素：
  - 页眉：ClarSyn 小 Logo + 章节标签 + 页码
  - 页脚：品牌名 + 章节名 + 页码
- 每页内容结构：
  - 主标题（结论句）
  - 支撑论据（2–4 条）
  - 视觉区（截图/图表/流程）
  - 来源提示（如需要，仅放章节名，不写内部文件路径）

## 6. 组件样式

- **卡片**：白底 `#FFFFFF`，圆角 18px，细阴影 `0 6px 18px rgba(31,42,68,.06)`
- **模块**：浅灰底 `#F8F9FC`，圆角 14px，轻阴影
- **标签 Tag**：胶囊形，圆角 999px，底色 `#EEF0F4` 或对应浅色底
- **表格**：表头浅灰底 `#EEF0F4`，行分隔线 `#EDEFF2`
- **引用 Quote**：渐变浅底 `linear-gradient(135deg,#FFFFFF,#F7F9FF)`，圆角 16px
- **截图**：深色截图加 1px 边框 + 14px 圆角 + 轻微投影，保持原始色彩
- **标注框**：浅色底 `#EAF1FC` 或 `#FDF3E4`，左边框 3px 强调色
- **流程图/架构图**：节点白底/浅灰底 + 细边框 `#D8DCE3`，连线 `#8B95A5`

## 7. SVG 图表规范

- 输出扁平 SVG：只使用 `rect / text / line / circle / path / polygon`，**不用 `<g>` 编组、不用滤镜依赖**
- 所有业务图使用透明底，不在 SVG 内画整页背景；背景由 `clarsyn-content-background.svg` 提供
- 节点文字不超过两行
- 关系线使用直线或正交折线，不用手绘曲线
- 配色沿用上述终版 HTML 色板；主路径可用 `#3B7DD8`，成功价值用 `#237A4C`
- 字号建议：标题 34px，副标 14px，正文 13–16px，注释 11–12px
- 组件资产文件：`portfolio/design-specs/a3-html-card-styles.svg`、`portfolio/design-specs/a3-html-icons-and-controls.svg`

## 8. 前端截图处理

- 截图统一以 16:9 或 4:3 裁切
- 截图上不加额外背景，保留原有深色界面
- 截图周围留白至少 6mm，避免拥挤
