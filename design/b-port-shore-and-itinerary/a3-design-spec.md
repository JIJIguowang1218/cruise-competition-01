## 1. 页面基础

- 页面尺寸：A3 横板（420mm × 297mm）
- 实际内容安全边距：上下左右 18mm
- 输出方式：HTML → 浏览器打印为 PDF，或导出 PNG
- 每页统一页眉：左：ClarSyn 小 Logo；右：章节标签 + 页码
- 每页统一页脚：品牌名 + 章节名 + 页码（不写内部文档路径）

## 2. 栅格与布局

- 采用 12 列栅格，页内容宽度约 384mm
- 每页允许三种版式：
  - 左文右图（默认）
  - 全宽图表
  - 三栏对比
- 页面内元素间距：
  - 标题与正文：12mm
  - 正文与图表：10mm
  - 段落间距：6mm
  - 卡片间距：6mm

## 2.5 Logo 变体

- 深色背景（前端/封面深色区）：使用 `assets/brand/clarsyn-title-preview.svg`
- 亮色背景（A3 页面默认）：使用 `assets/brand/clarsyn-title-light.svg`
- 浅底变体中，C/S 保持品牌色，`lar`/`yn` 普通字母使用中灰色 `#7A8494`，比原浅色更深、比纯深色更柔和

## 3. 字体

- 中文：`Noto Sans SC` / `Microsoft YaHei` / `PingFang SC`
- 英文：`Inter` / `Segoe UI` / `Helvetica Neue`
- 标题：36–48px，加粗
- 副标题：22–28px，中等
- 正文：14–16px，常规
- 注释/来源：10–11px，灰色
- 数字与时间：使用等宽数字 `font-variant-numeric: tabular-nums`

## 4. 颜色

- 背景主色：#F7F8FA（亮灰白）
- 正文墨水：#1A2233
- 次级文字：#5B6472
- 分隔线：#E3E6EB
- 主强调色（C）：#4C8DFF（ClarSyn 蓝）
- 次强调色（S）：#F0A43F（ClarSyn 琥珀）
- 成功/恢复：#2F9E63
- 危险/最高级：#E5484D
- 使用原则：
  - 每页最多 2 个强调色
  - 大面积只使用中性色
  - 表格/图表中颜色只用于区分关键信息

## 5. 统一栏目

- 每页固定元素：
  - 页眉：ClarSyn 小 Logo + 章节名 + 页码
  - 页脚：品牌名 + 章节名 + 页码
- 每页内容结构：
  - 主标题（结论句）
  - 支撑论据（2–4 条）
  - 视觉区（截图/图表/流程）
  - 来源提示（如需要，仅放章节名，不写内部文件路径）

## 6. 组件样式

- **卡片**：白底 #FFFFFF，圆角 8px，边框 #E3E6EB，阴影轻微
- **表格**：表头浅灰底 #EEF1F5，行分隔线 #E3E6EB
- **截图**：深色截图加 1px 边框 + 8px 圆角 + 轻微投影，保持原始色彩
- **标注框**：浅色底 #EEF4FF 或 #FFF7E8，左边框 3px 强调色
- **流程图/架构图**：浅色底，节点白底 + 细边框，连线 #8B95A5

## 6.1 页脚内容

- 左侧：章节名
- 右侧：ClarSyn + 当前页码 / 总页数
- 不放内部文件路径，避免评审看到实现细节

## 7. 图表风格

- 架构图/流程图使用 SVG 绘制，保证清晰
- 节点文字不超过两行
- 关系线使用直线或正交折线，不用手绘曲线
- 配色沿用中性色 + 少量 ClarSyn 蓝/琥珀

## 8. 前端截图处理

- 截图统一以 16:9 或 4:3 裁切
- 截图上不加额外背景，保留原有深色界面
- 截图周围留白至少 6mm，避免拥挤
